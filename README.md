# RulesConstructorForPatent

Консольное приложение для наполнения базы правил путеводителя по получению патента на работу в России. Правило описывает, какой документ получить, что для этого сделать, куда обратиться, от каких правил оно зависит и для каких категорий мигрантов действует.

Учебный проект по дисциплине «Проектирование информационных систем».

**Стек:** C# 12, .NET 8, Entity Framework Core 8, SQLite.

## Запуск

Нужен .NET SDK 8 или новее. Собранная программа запустится и там, где установлена только среда .NET 10.

```bash
dotnet run --project RulesConstructorForPatent
```

Можно открыть `RulesConstructorForPatent.sln` в Visual Studio. База `rules.db` создаётся в рабочей папке при первом запуске.

## Как устроен опрос

1. **Что нужно получить** — название правила и целевой документ.
2. **Руководство** — что сделать, куда обратиться (одна или несколько организаций) и что попробовать при отказе.
3. **Зависимость от других правил** — правила, которые нужно выполнить раньше; выбираются из базы.
4. **Для кого и в какой срок** — профили: цель въезда, гражданство, особый статус и срок. Правило действует, если мигрант подходит хотя бы под один профиль.

Условия профиля берутся из справочника `Catalogs/ProfilePropertyCatalog.cs` и охватывают пункты 5–6.4 таблицы ТЗ: патент и документы для него.

## Структура

```
RulesConstructorForPatent/
├── Program.cs    точка входа
├── ConsoleUi/    опрос, ввод с проверкой, вывод
├── Catalogs/     справочник условий профиля
├── Entities/     сущности EF Core
├── Services/     сборка правила: RuleDirector, RuleBuilder, ProfileFactory, RuleService
└── Data/         доступ к данным: RuleDbContext, RuleRepository, UnitOfWork
```

Паттерны: Builder с директором, Factory, Repository и Unit of Work.

## База данных

Зависимости хранятся в таблице `RequiredAccomplishedRules (RuleId, RequiredRuleId)`. Связи удаляются вместе с зависимым правилом, а правило, от которого зависят другие, удалить нельзя.

Схема создаётся через `EnsureCreated`, который не обновляет существующую базу: после изменения схемы удалите `rules.db`.

## Соглашения

Приватные поля — `m_camelCase`. Правило записано в `.editorconfig`, нарушение даёт предупреждение при сборке.
